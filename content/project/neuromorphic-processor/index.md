## Overview

A dedicated event-driven processor architecture designed to interface with dynamic vision sensors (event cameras), processing sparse spatio-temporal spikes with minimal latency and active power.

## Architecture & Contributions

- Asynchronous event decoding and routing logic.
- On-chip synaptic memory and leaky integrate-and-fire (LIF) neuron processing elements.
