## Overview

A compute-in-memory (CIM) based accelerator exploring efficient processing of sparse and hybrid attention mechanisms in vision and language transformers.

## Motivation

Attention layers incur heavy quadratic memory traffic and latency overheads. Computing in or near memory helps mitigate the memory wall in transformer inference.
